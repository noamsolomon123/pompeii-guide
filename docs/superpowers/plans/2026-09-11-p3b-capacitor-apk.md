# P3b Capacitor APK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wrap `www/` in Capacitor 8, build a debug APK locally (and on GitHub Actions), with camera/mic/GPS permissions working inside the WebView, and WebView remote-debugging on so the P4 simulation can drive it over CDP.

**Architecture:** Capacitor project at repo root (`capacitor.config.json`, `android/` committed as Capacitor recommends). No plugins yet: the app uses `getUserMedia`, `navigator.geolocation`, Web Audio directly; Capacitor's WebChromeClient bridges the runtime permission prompts once the manifest declares them. Local build uses the Android Studio JBR (JDK 21) and the SDK at `%LOCALAPPDATA%\Android\Sdk`. CI mirrors it on ubuntu.

**Tech Stack:** @capacitor/core, @capacitor/cli, @capacitor/android (v8), Gradle wrapper (generated), GitHub Actions (`actions/setup-java@v4` temurin 21, `actions/setup-node@v4` 22, `android-actions/setup-android@v3`).

**Prereq:** P3a merged (`www/index.html`, `www/app.js`, `www/stops.json`, `www/lib/**`).

### Task 1: Install Capacitor, init, add Android

- [ ] **Step 1: Install**
```bash
npm install @capacitor/core@8 @capacitor/android@8
npm install -D @capacitor/cli@8
```
- [ ] **Step 2: Config** — write `capacitor.config.json`:
```json
{
  "appId": "com.noam.pompeiiguide",
  "appName": "מדריך פומפיי",
  "webDir": "www",
  "server": { "androidScheme": "https", "hostname": "localhost" },
  "android": { "allowMixedContent": false, "webContentsDebuggingEnabled": true }
}
```
- [ ] **Step 3: Add platform**
```bash
npx cap add android
npx cap sync android
```
Expected: `android/` created with `app/src/main/assets/public/` containing a copy of `www/`.

```json

"apk:debug": "cd android && gradlew.bat assembleDebug"
```
- [ ] **Step 5: Verify tests still pass** (`npm test` unchanged count) and `git status` shows `android/` tracked except build dirs (Capacitor writes `android/.gitignore`).

### Task 4: GitHub Actions workflow

**Files:** Create `.github/workflows/android-debug-apk.yml`

- [ ] **Step 1:**
```yaml
name: android-debug-apk
on:
  push: { branches: [main] }
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: npm }
      - uses: actions/setup-java@v4
        with: { distribution: temurin, java-version: 21 }
      - uses: android-actions/setup-android@v3
      - run: npm ci
      - run: npm test
      - run: npx cap sync android
      - run: chmod +x android/gradlew && cd android && ./gradlew assembleDebug --no-daemon
      - uses: actions/upload-artifact@v4
        with:
          name: pompeii-guide-debug-apk
          path: android/app/build/outputs/apk/debug/app-debug.apk
```
- [ ] **Step 2:** Ensure `package-lock.json` is committed (needed by `npm ci`).
- [ ] **Step 3: Commit** `ci: build debug APK on push`
